# TechDelo Quality Dashboard

A browser demo of the manufacturing quality workflow our team presented at the 2026 CosmoHack Moscow final, where we placed third. The dashboard shows how a product moves through production, inspection and rework, and how the events and evidence follow that product.

[Open the demo](https://timofey-petrov-spb.github.io/texdelo-demo/)

## Try the recorded workflow

1. Open **Линия** to see the recorded production line.
2. Select a product to inspect its operations, recorded checks and evidence.
3. Switch to **Приёмка ОТК** to see the inspection view.

The demo runs in Russian. It uses HTML, CSS and JavaScript to replay bundled events. The event stream is stored in [demo/stream.jsonl](demo/stream.jsonl) and the entry point is [index.html](index.html).

Timofey Petrov was team captain and presenter. This repository contains the public dashboard demo.
